# 行情判断知识库

本文件用于约束 LLM 对规则引擎结果的复核。LLM 不能创造新规则，只能基于这里列出的证据判断规则结果是否需要降级、确认或在高置信度时覆盖。

## 输出原则

1. 默认信任规则引擎。
2. LLM 只能输出固定 JSON schema。
3. 置信度低于 `0.72` 时不得覆盖规则结果。
4. 缺少关键证据时必须 `action = "KEEP"` 或 `action = "DOWNGRADE_TO_SHOCK"`。
5. `TREND_SHORT` 必须比 `TREND_LONG` 更严格，因为回测中空头误判率高。
6. 不允许因为单根 K 线形态直接判断趋势。

## Regime 定义

### SHOCK

最近 42 根 4H K 线没有在最近 2 根内创出 7 天新高或新低，并且价格仍在 7 天区间内部。若趋势证据不足，应降级为 `SHOCK`。

做法：低于区间中线偏多，高于区间中线偏空，止盈至少 0.4%，止损必须有最大距离限制。

### TREND_LONG

必须同时满足：

- 最近 3 根 4H 的高点逐步抬高。
- 最近 3 根 4H 的低点逐步抬高。
- 7 天高点出现在最近 2 根 4H 内，或最近 3 根 4H 已突破 7 天高点。
- 1H EMA20 不低于 EMA60。
- 不是长上影冲高回落。

允许覆盖为 `TREND_LONG` 的最低证据：

- `three_bar_up = true`
- `near_or_break_7d_high = true`
- `ema20_1h >= ema60_1h`
- `confidence >= 0.72`

### TREND_SHORT

必须同时满足：

- 最近 3 根 4H 的高点逐步降低。
- 最近 3 根 4H 的低点逐步降低。
- 7 天低点出现在最近 2 根 4H 内，或最近 3 根 4H 已跌破 7 天低点。
- 1H EMA20 低于 EMA60。
- 最新 4H 收盘低于上一根 4H 收盘。
- 当前价格贴近 7 天低点，不能在区间中上部追空。

允许覆盖为 `TREND_SHORT` 的最低证据：

- `three_bar_down = true`
- `near_or_break_7d_low = true`
- `ema20_1h < ema60_1h`
- `last_4h_close < prev_4h_close`
- `price_position <= 0.35`
- `confidence >= 0.80`

若证据不足，必须降级为 `SHOCK_TREND_DOWN` 或 `SHOCK`。

### SHOCK_TREND_UP

用于“震荡但重心上移”，不是强趋势。必须同时满足：

- 最近 6 根 4H 有至少 3 次高点抬高。
- 最近 6 根 4H 有至少 2 次低点抬高。
- 4H 阴阳方向至少切换 3 次，说明不是单边趋势。
- 1H EMA20 高于 EMA60。
- 价格不应贴近 7 天低点。

如果高低点结构不连续，或 EMA 不支持，应降级为 `SHOCK`。

### SHOCK_TREND_DOWN

用于“震荡但重心下移”，不是强趋势。必须同时满足：

- 最近 6 根 4H 有至少 3 次低点降低。
- 最近 6 根 4H 有至少 2 次高点降低。
- 4H 阴阳方向至少切换 3 次，说明不是单边趋势。
- 1H EMA20 低于 EMA60。
- 价格不应贴近 7 天高点。

如果高低点结构不连续，或 EMA 不支持，应降级为 `SHOCK`。

### LIQUIDITY_SWEEP_REVERSAL

用于“连续上涨/下跌后的放量插针、扫止损后快速收回”，这是独立的高置信度反转信号，不改变 4H 主行情分类。LLM 不允许因为普通长影线直接建议开仓，必须同时满足：

- 前置结构有连续下跌或连续上涨背景，例如最近 15m 多根同向 K 线、24h 明显单边，或规则行情本身为趋势/震荡单边。
- 当前 5m K 线刺破最近约 4 小时高点/低点，随后收盘重新回到该关键位内侧。
- 影线必须明显长于实体，且影线占整根 K 线范围的大部分。
- 成交量必须明显放大，至少高于最近 20 根 5m 均量约 1.8 倍。
- 收盘必须完成确认：下插针做多需要收阳并收回前低上方；上插针做空需要收阴并收回前高下方。
- 默认需要下一根 5m 再确认：下插针后下一根不能再破针尖低点，且收盘继续站在收回位上方；上插针后下一根不能再破针尖高点，且收盘继续压在收回位下方。
- 止损只能放在针尖外侧，若针太大导致止损超过系统最大止损距离，应跳过而不是强行下单。

风险原则：

- 该信号默认关闭，必须通过回测或人工确认后启用。
- 仓位风险应低于普通强趋势信号，默认约 `0.8x`，即使动态仓位开启也有额外上限。
- 该信号不能替代 `TREND_LONG`、`TREND_SHORT`、`SHOCK_TREND_UP/DOWN`，只能作为特殊入场机会。

## 允许动作

- `KEEP`: 保持规则引擎结果。
- `OVERRIDE`: 高置信度覆盖为另一个 regime。
- `DOWNGRADE_TO_SHOCK`: 趋势证据不足，降级为 SHOCK。
- `BLOCK_TRADE`: 允许保留 regime，但禁止本轮开仓。

## 风险偏好

- `TREND_LONG`: 正常风险。
- `TREND_SHORT`: 低风险，除非证据极强。
- `SHOCK_TREND_UP`: 中低风险。
- `SHOCK_TREND_DOWN`: 低风险。
- `SHOCK`: 防守网格风险。

## 波动率自适应过滤

规则引擎会先按数值证据给出 `volatility_tier`，LLM 只能复核这个分层是否与证据一致，不能按币种名称写死判断。

### NORMAL

- `atr_pct = ATR_1H / price` 未达到高波动阈值。
- 24h 动量与 24h/72h 区间波动没有显著放大。
- 趋势入场可以采用标准 5m 回调确认。

### HIGH

任一证据达到高波动：

- `atr_pct >= 0.45%`
- `abs(ret_24h) >= 2.5%`
- `range_24h >= 3.5%`
- `range_72h >= 7.0%`

处理原则：

- 仍可使用标准 5m 回调确认，但必须增加突破回撤过滤。
- 如果是 `TREND_LONG`，价格不能从 7 天高点回撤超过约 `0.8 * ATR_1H` 后再追多。
- 如果是 `TREND_SHORT`，价格不能从 7 天低点反抽超过约 `0.8 * ATR_1H` 后再追空。
- 止损最小距离提高到至少 0.4%。
- 趋势止损应增加 ATR buffer。
- 若证据互相矛盾，优先 `BLOCK_TRADE` 而不是强行覆盖。

### EXTREME

任一证据达到极端波动：

- `atr_pct >= 0.75%`
- `abs(ret_24h) >= 4.5%`
- `range_24h >= 5.5%`
- `range_72h >= 10.0%`

处理原则：

- 趋势追单必须更保守，风险倍率必须降低。
- 止损最小距离提高到至少 0.5%。
- 如果只有 5m 金叉/死叉，没有 15m 与 1h 共振，应 `BLOCK_TRADE`。
- 趋势追单必须要求 5m、15m、1h 同向。

LLM 只在 HIGH 或 EXTREME 且规则结果为趋势/震荡单边时介入；NORMAL 行情不得频繁调用 LLM。

## 自适应品种规则

LLM 和规则引擎不得用币种名称直接写死“永远不做多”“永远不做空”“只允许某个币使用某策略”。品种名称只能作为流动性、合约特性、历史波动画像的辅助先验，不能作为最终开仓阻断条件。

如果需要阻断交易，必须落到可观测行情证据：

- 追高做多风险：`close_position_72h >= 0.70` 且 `ret_72h > 0.008`，说明价格已经处在 72h 区间偏高位置，scout 多单必须降级或阻断。
- 高位弱延续风险：`close_position_72h >= 0.78` 且 `ret_24h < 0.01` 且 `ret_72h < 0.005`，说明高位没有足够延续，确认多单也应谨慎。
- 中位弱延续确认多：`0.40 <= close_position_72h <= 0.52` 且 `ret_24h < 0.002` 且 `0 < ret_72h < 0.015`，说明价格处于区间中部且延续很弱，确认多单容易被反转止损。
- 低位追空风险：`close_position_72h <= 0.20` 且 `ret_24h > -0.025` 且 `ret_72h > -0.035`，说明空单可能在区间低位追空，应等待反弹或更强破位。
- 中高位弱空风险：`close_position_72h >= 0.55` 且 `ret_24h > -0.01` 且 `abs(ret_72h) < 0.005`，说明下跌趋势不够干净，scout 空单应阻断。
- 弱延续 scout 多单：`close_position_72h >= 0.60` 且 `ret_24h >= 0.008` 且 `0 < ret_72h < 0.010`，说明只是短期反弹而非中周期延续，应阻断 scout 多单。
- 浅反弹混合空单：`0 < ret_24h < 0.005` 且 `ret_72h < -0.005` 且 `0.30 <= close_position_72h <= 0.50`，说明下跌后有弱反弹但未重新转空，SHOCK_TREND_DOWN 空单应等待更强确认。
- 高波动低位空头噪声：`range_72h >= 0.10` 或 `volatility_tier in ["HIGH", "EXTREME"]` 时，空单不能在 `close_position_72h <= 0.18` 且 `ret_24h > -0.015` 的位置追入。
- 中低位弱空反弹：`0.30 <= close_position_72h <= 0.50` 且 `-0.02 < ret_72h < 0` 且 `-0.018 < ret_24h < 0`，说明跌幅不够干净，SHOCK_TREND_DOWN 确认空容易被反弹止损。
- 深跌 scout 空单：`close_position_72h < 0.20` 且 `ret_72h < -0.03`，scout 空单容易在低位被反弹止损，应等待更强确认。
- 中低位跌深 scout 空单：`0.20 <= close_position_72h <= 0.35` 且 `ret_72h < -0.02` 且 `ret_24h > -0.012`，说明 72h 已跌深但 24h 下跌不够，scout 空单容易被反弹止损。
- 跌深确认空：`close_position_72h < 0.20` 且 `ret_24h <= -0.03` 且 `ret_72h <= -0.05`，说明已经跌深，SHOCK_TREND_DOWN 确认空应避免追入。
- 下跌延续策略必须满足 `close_position_72h >= 0.20` 且 `ret_24h > -0.025`，避免在已经跌深的位置继续追空。
- 低波动 scout 噪声：`atr_pct < 0.0035` 且 `range_72h < 0.045` 时，不应做 scout 单，除非另有更高周期确认信号。
- SHOCK_TREND_DOWN 低位确认空：`close_position_72h <= 0.12` 时容易变成低位追空，必须等待反弹或改用 TREND_SHORT 确认。

当某个品种连续 2-3 天无单，LLM 复核应检查是否是行情结构不匹配当前策略，而不是建议添加币种白名单或黑名单。可建议开启 scout、切换到下跌延续、降低仓位或提高确认要求，但必须说明依据的 `range_24h/range_72h/ret_24h/ret_72h/close_position_72h/多周期方向一致性`。

仓位层面可以保留“资产画像”先验，但必须表现为风险倍率或最大仓位上限，并且应优先由历史波动、滑点、成交量、止损距离自适应计算。LLM 不应把这类先验升级成入场禁令。
