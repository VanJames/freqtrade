# 自动化交易策略分析与邮件提醒系统 —— 开发设计文档

## 1. 项目概述

本系统旨在构建一个智能交易辅助程序。通过组合分析 **CoinGlass 多周期清算地图** 数据与 **CCXT 实时 K 线形态**，捕捉主力资金（狗庄）的定点爆破方向（流动性猎杀）。系统完成多维度数据清洗与逻辑研判后，自动触发邮件通知，为交易员提供明确的操盘指令。

### 1.1 核心目标

* **自动化研判：** 判定当前市场方向是“做多”还是“做空”。
* **量化输出：** 明确给出触发条件（如：站稳某关键位）、目标止盈位、清算对手盘预测及技术依据。
* **实时通知：** 最终通过邮件形式发送结构化的策略报告。

---

## 2. 技术栈选型

* **开发语言：** Python 3.10+
* **代码生成环境：** OpenAI Codex
* **清算数据源：** CoinGlass 免费版网页清算地图（通过 Playwright 无头浏览器抓取；不使用官方付费 API）
* **K线数据源：** CCXT 库（对接 Binance 等主流交易所）
* **邮件服务：** Python 内置 `smtplib` + `email.mime`（支持 HTML 格式邮件）

## 3. 系统核心逻辑与算法设计

系统每隔固定周期（如15分钟/1小时）或在价格剧烈波动时触发执行，核心流程如下：

```
[数据抓取: CCXT K线 + CoinGlass 清算图] 
               │
               ▼
[主力意图识别: 寻找密集清算区 + 关键均线/形态验证]
               │
               ▼
[核心逻辑决策: 突破/反弹/跌破 状态机]
               │
               ▼
[模板合成与邮件投递]

```

### 3.1 多周期清算地图分析 (基于 CoinGlass)

系统需通过 Playwright 无头浏览器每隔 1 小时自动访问 CoinGlass 免费版网页清算地图，对清算图区域截图，并解析页面 SVG 图表的坐标属性。解析逻辑必须基于版本化的选择器/截图区域/坐标映射配置，将像素坐标逆向映射为价格数值，提取当前最高清算柱对应的价位，进而获取当前币种（如 ETH/USDT）的多周期（15M, 1H, 4H, 1D）清算密集区数据。抓取逻辑必须在页面结构、坐标映射或解析结果异常时失败并报警，不能静默返回错误数据。

* **多头清算堆积区（下方支撑/燃料）：** 统计现价下方密集开多、强平价集中的区间（如 $1711-$1650）。如果跌破关键位，这些多单将作为“燃料”引发连锁下跌。
* **空头清算堆积区（上方阻力/燃料）：** 统计现价上方密集开空、强平价集中的区间（如 $1746-$1780）。如果突破关键位，这些空单爆仓会转化为市价买单，推动暴涨。

### 3.2 实时 K 线形态分析 (基于 CCXT)

利用 CCXT 获取实时 K 线（15M/1H 周期），计算核心技术指标：

* **均线系统：** MA7、MA25、MA99。
* **量能验证（Volume）：** 爆仓针、无量反弹或放量破位的微观确认。
* **关键价格确认（定点防线）：** 检测收盘价是否“站稳”或“跌破”特定支撑/阻力。

### 3.3 核心决策矩阵

| 触发场景 | 清算地图表现 | K 线特征（CCXT） | 最终决策 |
| --- | --- | --- | --- |
| **场景 A：破位追空** | 下方存在大量**多头清算**订单（燃料充足） | 15M 实体线**跌破** MA99 等强支撑位 | **做空** |
| **场景 B：反弹诱空** | 上方密集**空头清算**，但短期抛压未耗尽 | 价格**无量反弹**至 MA25 阻力位滞涨 | **做空** |
| **场景 C：右侧稳健多** | 上方存在大量**空头清算**订单 | 价格放量冲高后，收盘稳稳**站稳**关键分水岭 | **做多** |

## 4. 邮件通知规范与模板

系统研判完成后，必须将以下要素动态填入 HTML 邮件模板中发送。

> ### 📧 策略提醒邮件格式规范
> 
> 
> * **邮件主题：** `【交易策略提醒】当前方向：[做多/做空] | 关键目标位：[价格]`
> * **邮件正文要素：**
> 1. **当前方向：** 明确给出【做多】或【做空】。
> 2. **触发条件：** 详述“因为当前价格**站稳/跌破了 [具体价格]**”。
> 3. **目标点位：** 预期的止盈目标是多少。
> 4. **清算对手盘预测：** 这一波主力动作“将会大规模**清算[多头/空头]**”。
> 5. **核心依据：** 结合多周期清算地图（xx价位有巨额强平盘）与 K 线（如：15分钟线爆量长上影、MA25 缩量回踩等）的文字化描述。
